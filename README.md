# 📊 프로젝트 관리 시스템

팀 협업을 위한 웹 기반 프로젝트 관리 도구입니다.

## ✨ 주요 기능

### 1. 📝 리포트 작성
- 프로젝트 개요 정보 관리 (프로젝트명, CPU, RAM, 출시지역, 일정 단계)
- 엑셀/CSV 파일 업로드를 통한 자동 이슈 분석
- 일정 단계별 맞춤 분석 리포트 생성

### 2. 📂 프로젝트 목록
- 저장된 모든 프로젝트 카드 형태로 표시
- 프로젝트 클릭으로 상세 정보 확인 및 수정

### 3. 💬 챗봇 URL 관리
- 팀 챗봇 링크 중앙 관리
- 타일 형태로 깔끔하게 표시
- 클릭 시 새 창에서 열기

### 4. ✅ Task 공유
- 팀원 간 업무 공유 및 진행 상황 관리
- 상태별 필터링 (진행중/완료/보류)
- 진행률 시각화 (프로그레스 바)

## 🚀 사용 방법

1. **설치**: 별도 설치 불필요
2. **실행**: `project-manager.html` 파일을 브라우저에서 열기
3. **설정**: 첫 실행 시 저장 경로 설정
4. **사용**: 각 탭에서 기능 활용

## 📋 시스템 요구사항

- **브라우저**: Chrome, Edge, Firefox 등 최신 브라우저
- **저장공간**: 브라우저 로컬 스토리지 사용
- **특이사항**: 인터넷 연결 불필요 (오프라인 사용 가능)

## 📊 이슈 파일 형식

엑셀 또는 CSV 파일에 다음 컬럼이 필요합니다:

| 컬럼명 | 설명 | 예시 |
|--------|------|------|
| Project | 과제 이름 | 프로젝트 A |
| Status | 상태 | Open, Resolve, Close |
| Priority | 중요도 | A, B, C |
| Frequency | 발생 빈도 | Always, Often, Rare |
| Reproducible | 재현 가능 여부 | Y, N |

## 🎨 주요 화면

### 리포트 작성
- 프로젝트 선택/입력
- 제품 사양 입력
- 이슈 파일 업로드 및 자동 분석

### Task 관리
- 타일 형태의 Task 카드
- 상태별 색상 구분
  - 🟢 진행중 (Ongoing)
  - 🔵 완료 (Complete)
  - 🟡 보류 (Hold)
- 진행률 프로그레스 바

## 💾 데이터 저장

- 모든 데이터는 브라우저의 로컬 스토리지에 저장됩니다
- 브라우저 캐시를 지우면 데이터가 삭제될 수 있습니다
- 중요한 데이터는 정기적으로 백업을 권장합니다

## 🔧 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **라이브러리**: 
  - SheetJS (XLSX) - 엑셀 파일 처리
- **저장소**: LocalStorage API
